# no place delay

client side fabric mod for minecraft 1.21.11. it cuts the delay between placing blocks and using items so you can place faster.

the vanilla cooldown after a use is about 4 ticks. this mod lowers it to a random number between your min and max (1 and 2 by default). it does nothing while you hold armor or an elytra.

## settings

open mod menu, find no place delay and click config. there is an on switch and min and max ticks sliders from 0 to 4. careful, putting both at 0 can get you flagged by anticheats.

## install

you need fabric loader, and mod menu with cloth config for the settings screen. put the jar from the releases page in your mods folder.

## build

`./gradlew build`, the jar ends up in build/libs.
